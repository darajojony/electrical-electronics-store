# VoltMart — Electrical & Electronics Store

Responsive bilingual (Khmer/English) storefront starter built with Next.js 15, React 19 and TypeScript.

## Features
- Khmer / English language toggle
- Responsive desktop and mobile homepage
- Product search and category filters
- Featured electrical and electronics products
- Demo shopping cart with quantity controls and subtotal
- Service, promotion and contact sections

## Run locally
Requirements: Node.js 20.9+ and npm.

```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Important
This is an initial frontend demo. Product names, prices, phone number and email are sample placeholders. The cart is browser-side only. Checkout, payments, database, inventory, admin login and order management are not yet connected. Replace all sample business details before publishing.
